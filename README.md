## 🧙‍♂️ About The Game

**RATS!** is a fast-paced 2D hobby project where you play as a wizard fighting off swarms of relentless rats. 

The project mainly serves as a creative playground to experiment with graphics programming, custom simulations, and game feel.

### ⚙️ Under the Hood

- **C++ & SFML** — Handles windowing, input, camera management, and 2D sprite rendering.
- **OpenGL & GLEW** — Custom rendering pipeline integrated alongside SFML's draw calls.
- **Compute Shaders** — Experiments with GPU-driven simulations (water, fire, and particle effects).
